We build an autonomous agentic LLM framework with tool use, planning, reasoning, and decision-making to tune configurations for RocksDB, CacheLib, and MySQL InnoDB end-to-end. We design a modular multi-agent pipeline (Executor, Extractor, Reflector, Searcher) combining insight-driven tree search and feedback-validation for safe configuration tuning. Achieved up to 5.75x throughput and 88% lower latency on real-world benchmarks, exceeding state-of-the-art baselines by 63% and prior LLM methods by 38%.
